# site3 images

Raw AI images live in `img/`; processed print/scan variants in `img/fx/` (palette PNGs, same pixel size as their source).
Generated by a seeded Python/Pillow/numpy script kept outside the site (reruns are byte-identical). Use the fx versions on pages; `.pixel` class on pixel fx for `image-rendering: pixelated`.
